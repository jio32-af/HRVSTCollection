HRVSTTsp

Geometric Euclidean TSP solver with Delaunay triangulation + MST candidate pruning. 400-trial benchmark: 0.000%–0.066% mean optimality gap, 94%–100% win rate vs. simulated annealing.

Read the paper (PDF) Source on GitHub ↗

Run it

git clone https://github.com/jio32-af/HRVSTCollection.git
cd HRVSTCollection/HRVSTTsp
pip install numpy scipy numba
python3 TSP.py selftest   # correctness checks
python3 TSP.py            # interactive benchmark
