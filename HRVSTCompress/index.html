Huffman coding

Min-heap priority queue → binary prefix tree → variable-length codes. Leaves carry byte value, printable character and frequency; edges carry the 0/1 bit weights.

Prefix property: no code is a prefix of another, so the bitstream decodes unambiguously left-to-right. Drag to pan · scroll to zoom · double-click to reset.
